Подключение

Выберите телефон из списка и введите код. Адрес и код показаны в приложении PocketNotes после нажатия «Запустить».

Заметки

Хранятся на вашем телефоне и сразу синхронизируются с этим устройством. Поиск работает по тексту заметок.

Файлы

Папки и файлы хранятся на телефоне. Перетащите файлы в окно или нажмите «Загрузить».

Приложение открыто по https, а телефон отдаёт файлы по http — браузер блокирует превью и видео. Открыть версию с телефона
