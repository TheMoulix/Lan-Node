Pocket Notes: сервер заметок на телефоне, редактор в браузере ПК.

Сборка APK на GitHub:
1. Создайте репозиторий на github.com (можно приватный).
2. Загрузите в него ВСЁ содержимое этой папки, включая скрытую папку .github
   (git: git init; git add .; git commit -m init; git branch -M main; git remote add origin <URL>; git push -u origin main).
3. Откройте вкладку Actions, дождитесь зелёной галочки у "Build APK" (3-6 минут).
4. Откройте завершённый запуск, внизу в Artifacts скачайте PocketNotes-apk (это zip, внутри PocketNotes.apk).
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

Чтобы получить прямую ссылку на APK: создайте тег v1.0 (git tag v1.0; git push origin v1.0),
файл появится в разделе Releases.

Использование: на телефоне нажмите "Запустить", на ПК откройте адрес с экрана
и введите код (или отсканируйте QR другим телефоном).
